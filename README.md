# Dance Analyzer 안내

춤 분석 프로젝트의 대표 저장소는 **[Joooooonha/dance-analyzer-service](https://github.com/Joooooonha/dance-analyzer-service)**입니다.

프로 댄서 영상과 연습 영상을 비교해 동작과 박자를 점검하도록 돕는 프로젝트입니다. 현재 구현, 실행 방법과 상세 기술 기록은 아래에서 확인할 수 있습니다.

- [프로젝트 소개와 실행 방법](https://github.com/Joooooonha/dance-analyzer-service#readme)
- [분석 엔진 기술 보고서](https://github.com/Joooooonha/dance-analyzer-service/blob/main/docs/analysis-engine-report.md)
- [엔지니어링 노트](https://github.com/Joooooonha/dance-analyzer-service/blob/main/docs/engineering-notes.md)

프로젝트를 소개하거나 공유할 때는 대표 저장소 링크를 사용해 주세요.
